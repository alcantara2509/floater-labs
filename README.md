# floaterlabs.com

Site da Floater Labs, estúdio de apps e web. HTML estático, sem build, publicado pelo GitHub Pages a partir da `main`.

- `index.html`: a página
- `404.html`: página de endereço não encontrado
- `img/`: imagem de compartilhamento e imagens do Wendly
- `logo/`: marca, símbolo, avatar e favicons; `logo/index.html` mostra o kit
- `CNAME`: domínio `floaterlabs.com`

Para ver localmente:

```bash
python3 -m http.server 8765
```

e abrir http://localhost:8765.
